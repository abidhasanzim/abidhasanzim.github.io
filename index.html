Projects

DQ-Agent: Agentic RAG Data Quality Investigator

An LLM agent that finds the root cause of data quality incidents in a 6M-row DuckDB warehouse, using SQL and 4-bit TurboQuant vector search over 5M documents.

Python, LangGraph, RAG, DuckDB  /  GitHub

FaultCast: Efficient LLM Work-Order Surveillance

An LLM pipeline that turns maintenance work orders into structured fault records with a 4-bit QLoRA-tuned Qwen2.5-3B (51% to 93% exact match), then flags fault surges with Poisson and CUSUM tests.

Python, PyTorch, QLoRA, FastAPI  /  GitHub

STDA: Secure Time-Series Domain Adaptation

Backdoor attacks and defenses for time-series transfer learning: data-poisoning triggers survive MAPU domain adaptation, and a compression + perturbation consistency defense cuts attack success from 53% to 13% on held-out subject pairs.

Python, PyTorch, ML Security, Domain Adaptation  /  GitHub
